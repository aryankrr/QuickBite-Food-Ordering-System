# QuickBite — Full-Stack Multi-Cuisine Food Delivery Engine

QuickBite is an end-to-end food delivery platform featuring a dynamic responsive frontend, an object-oriented Node.js/Express REST backend with finite state machine transitions, and a Supabase PostgreSQL relational database schema.

## Key Features
- **Multi-Cuisine Menu:** Hyderabadi Biryani, Artisanal Pizzas, Burgers, Masala Chai/Beverages, and Desserts with veg/non-veg toggle.
- **Customization Engine:** Item-level portion sizing (Regular, Medium, Large) and add-ons with dynamic subtotal recalculation.
- **Real-Time Lifecycle Tracking:** Stage-by-stage order monitoring (Placed -> Preparing -> Out for Delivery -> Delivered).
- **Admin Dispatch Terminal:** Live kitchen queue and state machine dispatch transition controls.
- **Architecture Aligned:** Direct mapping to UML Class models, ERD relations, and finite state validation.

## Tech Stack
- **Frontend:** HTML5, Tailwind CSS, JavaScript (ES6+), FontAwesome
- **Backend:** Node.js, Express.js, CORS
- **Database:** Supabase (PostgreSQL)
